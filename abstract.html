Executive Project Abstract

The Smart Campus Canteen Pre-Ordering & Live Token System eliminates long lunch queues and chaotic food counters in college campuses through an intuitive full-stack web application. Built with React and Spring Boot (Java), the platform enables students to pre-order meals from dynamic menus and receive instant digital tokens for scheduled pickups. Canteen staff manage incoming orders through a real-time kitchen queue, while a public TV display board flashes ready tokens for hassle-free collection. Secured with JWT authentication and powered by Spring Data JPA, this project modernizes campus dining into a fast, transparent, and completely queue-free experience.

Key Modules & Capabilities
1. Student Portal (React)
  • Categorized digital menu (Breakfast, Lunch, Snacks, Drinks).
  • Dynamic cart with quantity controls and instant bill calculation.
  • Time-slot selection to align order pickup with class breaks.
  • Personal order history with real-time state pill updates.
2. Canteen Staff Operations (Spring Boot + React)
  • Live incoming order board sorted chronologically by pickup time.
  • One-touch lifecycle transitions: Placed ➔ Preparing ➔ Ready.
  • Real-time item availability toggle (Mark "Sold Out" instantly).
  • Daily sales tally and order quantity summary.
3. Public Live Token Display Screen
  • Full-screen TV dashboard for high-visibility dining hall mounting.
  • Divided status columns: Now Preparing vs Ready for Pickup.
  • High-contrast visual indicators allowing instant token identification.
  • Eliminates physical counter crowds and verbal order callouts.
4. Security & Data Management
  • Stateless authentication using JSON Web Tokens (JWT).
  • Role-Based Access Control: ROLE_STUDENT & ROLE_CANTEEN_STAFF.
  • Relational database mapping for Orders, OrderItems, and Users.
  • Database constraints to eliminate duplicate tokens and race conditions.
